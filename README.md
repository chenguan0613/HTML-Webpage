# HTML-Webpage

手写 HTML 网页仓库，存放「25时，Nightcord见」的百科页面和相关资源。

## 目录结构

```text
HTML/                 # 手写的网页
  register_page.html    # 组合百科主页（简介、主线剧情、人物关系、音乐作品）
  kanade_profile.html   # 宵崎奏 角色介绍页
docs/
  images/             # 页面用到的图片（专辑封面、背景图等）
  music/              # 音乐作品对应的本地音频（.mp3）
```

## 本地查看

直接用浏览器打开 `HTML/register_page.html` 即可，无需搭建任何环境。

> 页面通过相对路径 `../docs/images/` 和 `../docs/music/` 引用图片与音乐，
> 请保持上述目录结构不变，否则图片和音乐会加载不出来。
